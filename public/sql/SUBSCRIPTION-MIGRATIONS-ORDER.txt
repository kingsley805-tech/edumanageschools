Run these scripts in the Supabase SQL Editor (Dashboard → SQL → New query), in order.
After the last script, run: NOTIFY pgrst, 'reload schema';

1. apply-platform-saas-control.sql
2. apply-organization-subscription-billing.sql   ← creates get_organization_subscription_access RPC
3. apply-admin-signup-no-admin-key.sql
4. apply-subscription-reminders-and-comp-grant.sql
5. apply-subscription-package-permissions.sql   ← module catalog, RBAC sync, plan reapply RPC
6. apply-sms-subscription-billing.sql           ← SMS add-on checkout, enable_sms, sync_school_sms_entitlement
7. apply-subscription-package-full-config.sql   ← SMS credits, student/teacher limits, activation hooks
8. apply-platform-subscription-checkout-rpc.sql ← Paystack init with package + SMS (fixes GHS 49-only charge)
9. apply-subscription-module-access-fix.sql       ← CRITICAL: module entitlements after payment, self-heal RPC

Attendance SMS (teacher page + register):
- apply-attendance-sms-system.sql (if not already applied)
- apply-attendance-sms-teacher-page.sql ← attendance_sms_logs, templates, master toggle
- Deploy edge function: send-attendance-sms
- Secret: ARKESEL_API_KEY

Optional (fixes lesson_notes 404 on admin dashboard):
9. apply-lesson-notes.sql
10. apply-lesson-notes-nav.sql
11. apply-grant-all-modules-rpc.sql (adds one-click "Grant all modules")

Until step 2 is applied, the app uses a legacy fallback (full access for schools without a subscription row).
New admin signups require step 3 before they get a pending subscription row.

Mandatory admin lock after signup (step 3):
- Creates school_subscriptions with status = pending
- Admin can log in but cannot use /admin, /accountant, /auditor, or /settings until payment or Super Admin grant

Super Admin unlock (step 4):
- grant_complimentary_subscription on Tenant Detail
- grant_all_school_module_entitlements (optional step 7)
